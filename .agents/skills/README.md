These are instruction-only project skills. They need no network, package installation, lifecycle
hook, telemetry, shell script or service to be read and followed. They do not install Ponytail's
native plugin or its optional band/board features.

To update, read the proposed upstream revision first, replace both `SKILL.md` files and the license
from that exact revision, update this pin, and review the instruction diff. Do not download a
floating branch on every task or edit upstream text to weaken a project requirement.
