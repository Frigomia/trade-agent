# Scan results — approved direction

The owner chose A, the separate page, on 2026-10-28 after being offered
`a-page.html`, `b-inline.html` and `c-drawer.html`.

Entry: Today’s scan bar, through its set-aside count or Scan results link.
Route: `/today/scan-results`. Uses the same saved latest scan as Today, with
no provider calls or run cost. Back to Today stays visible.

Soft light/dark panels; one column on phones, results plus coverage on computers.
The saved time and older-scan warning stay above the results. Research that did
not qualify and confirmed thesis exclusions explain the immutable set-aside count.
Screening exclusions and rejected mentions have separate headings and counts.
Each exclusion shows its explanation and cited links. Mentions show their
rejection reason and the original context, labelled unverified web text.

No scan, nothing set aside, old scan, missing legacy details, loading and read
failure all have explicit copy. Older scans cannot recover non-qualifying research
that was never saved. All provider/web text renders as text; source links use
`safeHref` through the existing SourceLink component.
