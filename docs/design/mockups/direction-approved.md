## What this folder is

The baseline the app was built from: `direction-A-dark-and-light.html` (the chosen direction, dark and light), `user-sections.html` and `auth-and-admin.html` (the user and admin screens). The written spec is `docs/superpowers/specs/2026-09-28-frontend-design-direction-design.md`; the product record is `PRODUCT.md` and the design tokens are in `DESIGN.md`, both at the repository root.

Direction A, named "Emerald Glass" in the spec (teal accent, dark and light). The user's words were not recorded. `docs/ARCHITECTURE.md` points to this folder for the responsive pass ("checked against `docs/design/mockups/`").

Note: the Soft direction chosen on 2026-10-20 (see `../today-discovery/direction-approved.md`) uses a blue accent for the new screens, so `DESIGN.md` needs updating when they are built.
